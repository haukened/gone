# Gone

> Gone shares a secret exactly once. It encrypts a password, token, key or file in the sender's browser (or the gone CLI), the server stores only ciphertext, the key travels in the link's #fragment, and the secret is deleted after one read. It is open source (AGPL-3.0), free, and self-hosted.

- Public instance: {{ site.Params.app }} (anyone can use it; for anything important, run your own)
- Install the CLI on Linux or macOS: `curl -fsSL {{ "install.sh" | absURL }} | sh`
- Run your own: one static binary or container, SQLite storage, no external services, behind HTTPS ({{ (site.GetPage "/docs/deploy/readme").Permalink }})
- Source: {{ site.Params.repo }}
