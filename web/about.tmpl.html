What is Gone?

Go + One = Gone

Gone is a tool for sharing secrets privately, readable only one time. The server component is written in Go, a language designed for simplicity and efficiency by Google. The client-side application is built with vanilla JavaScript and modern WebCrypto APIs to perform encryption and decryption directly in your browser.

Gone is open source software. The source code is available on GitHub under the GNU Affero GPL v3.

What encryption does Gone use?

Gone uses AES-256-GCM provided by WebCrypto APIs for client-side encryption, which is the same encryption trusted by banks, governments, and security-conscious organizations worldwide.

How Gone keeps secrets secret

Gone is designed so the server never learns your secret. The critical cryptography happens entirely in your browser before anything is sent over the network.

High-level flow

  1. You type a message and/or attach files in the form. Before anything leaves your device, the browser generates a fresh, random encryption key.
  2. Client-side encryption (using modern WebCrypto primitives) packs the message and files together and transforms them into a single opaque blob. File names and types are encrypted too.
  3. Only the encrypted blob is sent to the Gone server. The key never leaves the browser.
  4. The server stores just that blob plus minimal metadata (expiry time and one-time state).
  5. A shareable URL is produced. The secret key is embedded in the URL fragment (the part after #), which browsers never send to the server.
  6. The recipient opens the URL and presses Open; their browser extracts the key locally and downloads the encrypted blob. From that moment the secret is reserved for them alone; anyone else who opens the link sees that it is gone.
  7. Decryption happens client-side; the browser verifies every byte arrived intact before showing anything. The server remains blind to the plaintext the entire time.
  8. Confirmed deletion: once the recipient's browser has the complete secret, it tells the server to delete it. If that confirmation never arrives (closed tab, dropped connection), the server deletes it automatically a few minutes later. Either way, it can never be read twice.

File attachments

  • Attach up to 10 files of any type. The message and all files share one size limit, shown on the form.
  • Files are encrypted in your browser exactly like the message; the server cannot see their names, types, or contents.
  • The recipient downloads each file individually or all at once. Gone warns them before leaving the page with files still unsaved, because the secret cannot be opened again.
  • File names are cleaned up (folders and hidden control characters removed), and uncommon file types are saved as generic downloads so they can't run in the browser.

Optional passphrase

  • The sender can add a passphrase. Opening the secret then takes both the link and the passphrase, so a leaked link alone is not enough.
  • Send the passphrase separately from the link, for example the link by email and the passphrase by phone. Gone never stores the passphrase and cannot recover it.
  • Your browser stretches the passphrase with PBKDF2 (600,000 rounds) and mixes it with the link's key. Every wrong guess costs real time, but a short or common passphrase can still be guessed by someone who has the link. Use Generate for five random words.
  • As you type, Gone shows the passphrase's estimated entropy in bits and roughly how long it would take to guess. The estimate assumes someone who already has the link and can make a million guesses a second against the stretched passphrase. It's a guide, not a guarantee: names, dates, and well-known phrases fall faster than it shows.
  • If the passphrase is wrong, the recipient can try again as many times as they need without downloading the secret again.
  • Opening the link uses up the secret even if the passphrase is wrong. A passphrase keeps a leaked secret unreadable, but cannot stop someone with the link from destroying it.
  • Generated passphrases use the EFF short wordlist by the Electronic Frontier Foundation, licensed under CC BY 3.0 US.

Why this matters

  • Zero server knowledge: Compromise of the storage tier yields only ciphertext.
  • Ephemeral access: One-time retrieval shrinks the attack window.
  • Short TTLs: Automatic expiry further limits exposure if a link lingers.
  • No password reuse risk: You never transmit existing credentials in the clear.

Threat model notes

  • Always verify you are on HTTPS (the app warns if not).
  • The secrecy guarantee assumes the sender's and recipient's browsers are not compromised.
  • Anyone who obtains the full share URL (including its key component) can decrypt the secret until first read or expiry, unless the sender added a passphrase.
  • If someone else opens the link first, the intended recipient will see that the secret is gone, a clear sign the link was intercepted.
  • Attachments are only as safe as the device they are saved to; delete downloaded files when you no longer need them.

What does the GNU Affero GPL v3 mean for you?

Gone is free, open source software under the GNU Affero General Public License version 3 (AGPLv3). Here is what that means in plain English. This is a summary, not legal advice; the license itself is what counts.

If you use Gone to send or open secrets

  • You have no obligations. Using Gone puts no license terms on you or on what you share.
  • If someone runs a modified version of Gone, they must let you download its source code.

If you host or change Gone

  • You may run Gone unmodified for any purpose. Leave its copyright and license notices in place.
  • You may change Gone however you like. If other people use your changed version over a network, you must offer them its complete source code, free of charge and under the AGPLv3. A link in the footer is enough.

  • Changes you keep to yourself, with nobody else using them, carry no obligation to share.
  • If you give someone a copy of Gone, such as a container image, include the license and the source code or tell them where to get it.

If you are a company

  • You may use Gone commercially, including running it as a paid service for customers.
  • The same rules apply as for anyone else. Unmodified, there is nothing to share. Modified, anyone who uses your version over a network must be offered its source code under the AGPLv3.
